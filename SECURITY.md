# Security

Do not publish production credentials, private keys, runtime state, DNS logs, user files or packet captures in issues or pull requests.

This preview uses privileged Linux networking operations and is intended for a trusted local management network. MAC authorization does not prevent MAC spoofing. The subscriber HTTP portal does not provide transport confidentiality.

No private vulnerability-reporting channel is configured in this source package. Before publishing a public repository, its owner should enable GitHub private vulnerability reporting. Avoid posting exploit details publicly until a reporting channel is available.
